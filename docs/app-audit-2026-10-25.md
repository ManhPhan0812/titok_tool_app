# Whole-application simulation — 2026-10-25

Baseline: `852a888`, development source version 1.0.4. No release build,
publication, real project migration or live cloud request is part of this audit.

## Scope and isolation

The complete application pytest suite runs against private runtime/project roots.
It includes Manual/Auto/Batch processing, source replacement, SRT import/removal,
subtitle edits and incremental voice reuse, translation checkpoints, pause/resume,
restart/cancel, resource installation/update, download queues, social-publication
queues/navigation, preview playback, export ranges/speed, cleanup and file locks.

Real-pipeline simulations use tiny valid MP4/WAV/MP3 fixtures and the production
queue, metadata store, artifact graph, FFmpeg extraction/mixing/rendering/export.
AI/cloud services and provider failures are deterministic substitutes. Offscreen
Qt exercises actual QML controls, focus, IME, dialogs and component lifetimes.
These tests do not establish real model speech quality, customer GPU performance,
multi-hour memory behavior, or current Douyin/TikTok/Google service availability.

Storage/export and VieNeu clone modules run separately, as required by the
repository test runner, to prevent unrelated Qt singleton readers from sharing
patched fixture paths. No test is dropped from those modules.

## Reproduced corrections

1. An open Gemini guidance editor could restore the previous story after an
   asynchronous source replacement retained the same project/video ID. Its
   owner now includes the source generation/creation identity. The old editor
   is released on source change; saving checks the exact persisted source key
   and rejects attempts while that video is being replaced. Other settings
   edits do not change this key or discard an active draft.
2. A focused, unedited watermark field deferred a model update but never
   reconciled it after blur. It now tracks pending source synchronization and
   applies it after clean focus/composition completion. Dirty user input still
   wins over an intervening model refresh and commits only once; Vietnamese
   preedit/composition tests remain intact.
3. The Manual workspace's opening placeholder referenced the Auto workspace
   Loader. Each Loader now has the correct identity, and Manual's placeholder
   tracks its own loading state.

The initial full suite also found two failing language-guard cases. Known
unsupported VieNeu language choices now reject before subtitle/source lookup;
imported SRTs still receive the more specific content warning. These failures
involved lightweight configuration fixtures, not evidence of two additional
customer crashes.

The D-to-C export fixture formerly always skipped because portable runtime
initialization redirects `tempfile` and environment paths to D. The test now
uses a private, automatically removed directory under the preserved native
Windows profile for this explicitly external export destination. It successfully
verifies the cross-volume copy and that deleting the project preserves the
external export. Production storage policy is unchanged.
